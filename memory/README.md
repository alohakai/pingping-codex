# Memory

这里为“小萍萍”的长期记忆文件预留空间。

- `chats/`：每个飞书会话独立的运行时记忆。目录名是 chat ID 的 SHA-256
  短哈希，避免在文件路径中暴露真实会话 ID。
- `workers/`：将来供跨会话 worker 使用的运行时记忆。
- `shared/`：允许人工维护、可提交到仓库的公共知识与约定。
- `shared/private/`：本机私有的共享记忆，不提交到 Git。

机器人启动或恢复 Master 时，会把当前会话专属目录写入运行时指令。记忆文件
中禁止保存 App Secret、访问令牌、密码、Cookie 或其他敏感凭证。
